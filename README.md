# Spese Casa

Budget di casa per iPhone: entrate, uscite e saldo mese per mese, riepilogo annuale, backup e CSV.
Web app installabile che funziona anche senza rete.

Apri **https://oshadha2010-cloud.github.io/spese-casa/** in Safari → Condividi → Aggiungi alla schermata Home.

I dati restano sul telefono (memoria della web app): questo sito contiene solo il codice dell'app.
